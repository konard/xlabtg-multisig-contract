# F-05 — Контракт не проверяет диапазон индексов владельцев при инициализации

## Краткое описание

`create_init_state` принимает готовый `owners_info` dictionary и не проверяет, что ключи владельцев образуют диапазон `0 .. n-1`. Впоследствии голос владельца устанавливает бит `1 << i`, а `cnt_bits` сериализуется ровно в `n` бит. Индекс `i >= n` может привести к ошибке сериализации состояния.

Стандартный `new-multisig.fif` создаёт последовательные индексы. Следовательно, это deployment footgun при нестандартном доверенном tooling, а не удалённая уязвимость корректно созданного кошелька.

## Предпосылки

- Доверенный deployer или нестандартный локальный tooling создаёт некорректный `owners_info`.
- В dictionary есть владелец с индексом `i >= n`.
- Этот владелец отправляет корректно подписанный запрос.

Удалённый атакующий не может изменить owner dictionary уже развёрнутого контракта.

## Корневая причина

Контракт доверяет deployment state. `cnt_bits |= 1 << i` не сопоставляется с `n`, а затем `store_uint(cnt_bits, n)` ожидает значение, помещающееся в `n` бит.

## Шаги воспроизведения

1. Локально вызвать `create_init_state` с `n = 2`, но owner key по dictionary index `2`.
2. Развернуть полученное state init в emulator.
3. Отправить корректный запрос от владельца index 2.
4. Проверить ошибку при сериализации `cnt_bits` в два бита и отсутствие сохранения заказа.

Исполняемый PoC не приложен; live mainnet/testnet не использовались.

## Ожидаемый и фактический результат

Ожидание: state constructor должен отвергать неконсистентную конфигурацию.

Фактически invariant обеспечивается штатным deployment script, а сам код контракта его не проверяет.

## Влияние

Локальная ошибка конфигурации может сделать конкретного владельца/заказы неработоспособными. Attacker-controlled path и влияние на корректно развёрнутый контракт отсутствуют.

## Рекомендации

- валидировать `k <= n`, количество ключей и диапазон/уникальность owner indices в deployment tooling;
- документировать invariant;
- при совместимой миграции добавить validation в constructor path.
